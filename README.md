# ZERO AI Assistant

ZERO is a sleek, modern AI assistant frontend interface built with TypeScript, HTML, and CSS.

## Features
- **TypeScript Integration:** Source written in TypeScript and compiled to pure vanilla JS.
- **Local Persistence:** Chat history and recents saved directly in `localStorage`.
- **Search:** Search recent chat titles and message contents easily.
- **Adaptive Inputs:** Textarea expands dynamically, with context-aware `Enter` / `Shift+Enter` key behavior on mobile and desktop.
- **Theme Support:** Built-in Light and Dark themes.
