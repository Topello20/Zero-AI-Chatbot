ZERO AI Assistant

ZERO is a sleek, modern AI assistant interface built with TypeScript, HTML, and CSS. It provides a clean chat experience with persistent conversations, search, responsive inputs, and light/dark themes.

✨ Features

- 💬 AI Chat Interface — Clean and responsive conversational UI.
- ⚡ TypeScript — Source code is written in TypeScript and compiled to JavaScript.
- 💾 Local Persistence — Chat history and recent conversations are stored in "localStorage".
- 🔎 Search — Quickly search through recent chat titles and message content.
- ⌨️ Smart Input — Dynamic textarea sizing with context-aware "Enter" and "Shift + Enter" behavior.
- 🌗 Theme Support — Switch between Light and Dark themes.
- 📱 Responsive Design — Designed to work smoothly across desktop and mobile screens.

🛠️ Built With

- TypeScript
- HTML5
- CSS3
- JavaScript
- LocalStorage API

🚀 Getting Started

1. Clone the repository

git clone https://github.com/Topello20/Zero-AI-Chatbot.git
cd Zero-AI-Chatbot

2. Install dependencies

npm install

3. Start the development server

npm run dev

Open the local development URL provided by your terminal to view ZERO in your browser.

📁 Project Overview

ZERO focuses on building a modern AI assistant experience while keeping the frontend lightweight and easy to understand. It uses browser-based storage to preserve conversations locally without requiring a separate database.
